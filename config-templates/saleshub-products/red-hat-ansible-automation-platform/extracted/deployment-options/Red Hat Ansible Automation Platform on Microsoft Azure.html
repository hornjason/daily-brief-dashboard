Features and benefits

Runs in your cloud

Deploy and run the Ansible Automation Platform managed app and self-managed app in your Microsoft Azure cloud, then extend your automation to private clouds, on-premise datacenters, edge locations, and other public clouds—wherever you do business.

Integrates with Azure services

You get the complete Ansible Automation Platform as well as integration with Azure services such as Azure AD, Azure Virtual Machines, Azure Database Services, Azure Container Registry, Azure Key Vault, and more. It also includes the full Ansible collection for Microsoft Azure.

Managed application fully supported by Red Hat

We manage, service, and support the application so your IT team can focus on delivering automation strategies for a more efficient and scalable business.

Counts toward spend agreements with integrated Azure billing

Integrated billing means one bill—and full visibility into cost. Also, if you have a spend agreement with Microsoft, the costs of this offering count toward that amount.

Offers flexibility and speed

Ansible Automation Platform on Azure combines the power of cloud computing with the convenience of a managed offering. IT teams can quickly automate and scale in their cloud. Deploy the app and start automating your Azure resources in minutes.
