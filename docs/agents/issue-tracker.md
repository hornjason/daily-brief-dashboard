# Issue Tracker

Issues are tracked in **GitHub Issues** on the `hornjason/asaCommandCenter` repo (private).

**CLI:** `gh` (GitHub CLI)

**Creating issues:**
```
gh issue create --repo hornjason/asaCommandCenter --title "..." --body "..." --label "needs-triage"
```

**Listing issues:**
```
gh issue list --repo hornjason/asaCommandCenter
gh issue list --repo hornjason/asaCommandCenter --label "ready-for-agent"
```

**Viewing an issue:**
```
gh issue view <number> --repo hornjason/asaCommandCenter
```

**Commenting:**
```
gh issue comment <number> --repo hornjason/asaCommandCenter --body "..."
```

**Closing:**
```
gh issue close <number> --repo hornjason/asaCommandCenter
```

**Adding/removing labels:**
```
gh issue edit <number> --repo hornjason/asaCommandCenter --add-label "ready-for-agent" --remove-label "needs-triage"
```

All issue comments generated by AI during triage must start with:
```
> *This was generated by AI during triage.*
```
