The Challenge Workflow

Change an input → regenerate → see the output change. This is how the team demonstrates innovation.

1

Capture Baseline

Open any customer account → read the current brief and account plan. This is the "before" state. Note the signal counts, graph edges, and quality score.

Dashboard → [Select Customer] → Account Plan
Score: 95.2% | Sections: 12 | Initiatives: 4
Customer Success: 67% ← example lowest category
2

Change an Input

All changes happen through the dashboard UI or Google Drive — no code or config editing required.

Add a Document to Google Drive
Drop a file (competitive alert, meeting notes, partner update, expansion opportunity) into the customer's shared Drive folder
Effect: Gemini reads the new doc on next regeneration — content is synthesized into the brief, account plan, and all consumers automatically. Verified: adding a VMware migration alert produced a new “VMware to OpenShift Consolidation” initiative in the account plan.
Refresh Data Sources
Dashboard → Data Freshness → click "Refresh" on any source (Cases, Pipeline, Subscriptions)
Effect: Scraper re-pulls live data — new cases, updated pipeline, changed subscriptions flow in
Regenerate Account Intelligence
Customer page → Intelligence panel → click "Generate" — Gemini re-researches the company
Effect: Fresh company intel with latest news, leadership changes, strategic context
Generate Account Plan
Customer page → Account Plan tab → click "Generate" — builds from 9 inputs + 11 quality checks
Effect: New plan with updated signals, re-scored quality gate, uploaded to Google Drive
Generate Meeting Prep
Customer page → Calendar strip → click upcoming meeting → "Generate Prep"
Effect: Pre-call brief with attendee context, recent activity, talking points from 10 signal sources
Generate Product Intel
Customer page → Products tab → click "Generate" on any product
Effect: Per-product expansion angles, feature maturity, lifecycle status refresh
Regenerate Customer Brief
Customer page → Brief section → click the refresh icon to regenerate
Effect: Brief rebuilds from all 9 inputs — recommended actions, signal priorities, cross-references update
3

Regenerate

Click regenerate. The pipeline re-runs with the modified input. Watch the provenance table update — it shows exactly which sources loaded and how many tokens each contributed.

Provenance after injection:
signal-loader: loaded (2,800 tokens — +400 from new case)

intelligence: loaded (5,000 tokens)
solution-plays: loaded (1,200 tokens — +400 from new play)
email-intelligence: now loaded (800 tokens — NEW)
4

Compare Before / After

Check each consumer to see how the refreshed data changed the output. The provenance panel (Theme A) would explain WHY.

Before (baseline)

Account Plan score: 95.2%
Initiatives: 4
Brief: 6 recommended actions
Meeting Prep: based on last week's data
No recent case context in any consumer

After (refresh + regenerate)

Account Plan score: changed — new signals scored
+ New initiative surfaced from fresh data
+ Brief: recommended actions re-prioritized
+ Meeting Prep: new cases appear as talking points
+ Campaigns: outreach updated with latest context
How to verify the intelligence is working
Check each consumer after regeneration: Brief → did recommended actions change? Account Plan → did the score or initiatives change? Meeting Prep → do talking points reflect new data? Campaigns → is the outreach updated? Same signal change, different outputs — that proves the cross-reference engine works.

The 60-Second Demo Script
