The Challenge Workflow

Change an input → regenerate → see the output change. This is how the team demonstrates innovation.

2

Change an Input

Pick any of the hidden inputs and modify it. Each change produces a different effect on the output.

Inject a new support case
Add a Sev1 case to cases.json → triggers cross-reference with existing signals
Effect: New case appears in brief, graph edges increase, recommended actions update
Update the CY27 planning deck
Edit cy27-planning-deck.txt → changes strategic context and CY27 requirements
Effect: Partner growth strategy, sovereignty section, and timeline all shift
Add email threads
Add customer emails to the email cache → email intelligence loads for next generation
Effect: Engagement timeline populates, contact names surface, meeting prep improves
Modify the quality threshold
Change PASS_THRESHOLD from 75 to 90 → forces higher-quality regeneration
Effect: Plans retry more, output depth increases, weaker sections get rewritten
Add a solution play
New solution play matched to customer's tech stack → appears in initiatives
Effect: New initiative with estimated TCV, specific Red Hat product positioning
Change the playbook guidance
Edit playbook.md → different planning methodology or emphasis
Effect: Plan structure shifts, section depth changes, different strategic framing
