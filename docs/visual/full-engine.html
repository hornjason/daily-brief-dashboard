Layer 4 — Cross-Reference Engine

Weighted Confidence Scoring

Detects signal specificity (customer / industry / general), applies score boosters (+revenue, +severity, +renewal urgency, +product match, +confidence), enforces time decay and budget caps per section. A security advisory matched to a customer running the affected version with a renewal in 47 days = highest priority.
