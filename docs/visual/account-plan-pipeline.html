Stage 2

Context Orchestrator Enrichment

buildConsumerContext loads customer signals via ensureFresh, then templateAll deterministically assembles signal context + verified solution plays section for grounding. No hallucination — every play citation must exist in the VERIFIED SOLUTION PLAYS section.

Stage 3
Generate

Gemini Multimodal Generation

callGeminiForAccountPlan sends 7 sources as text context + questions PDF as base64 vision input. Gemini reads the questions image while processing intelligence. Structured responseSchema (ADR-040) ensures all 12 required sections. Temperature fixed at 0.3 for consistency.

Quality Gate (11 Checks)

validateAndRetry runs accountPlanValidator — 11 checks for required sections, no placeholder text, content depth, grounding rules compliance. Below threshold = regenerate with formatFailureFeedback. Mandatory pass before Drive upload (ADR-024 compliance).
