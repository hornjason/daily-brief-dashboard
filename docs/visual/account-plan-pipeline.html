Challenge Theme Mapping — What to Build

A: "Show Your Work"

Innovation, Technical Excellence, UX
  • Expose the provenance table in the UI
  • Show the 9 inputs and which loaded
  • Display the 11 quality checks with pass/fail
  • Data maturity indicator: "6/7 sources loaded"

Innovation, Technical Excellence
