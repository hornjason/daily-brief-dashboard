The Opportunity — What's Hidden

Today: User presses a button → output appears. Zero visibility into what went in, which sources loaded, what's missing, or how to improve it.

The data exists. The ProvenanceEntry[] array already tracks { source, loaded, tokenEstimate } for every input. buildConsumerContext() assembles 3 layers: signals → templateAll → intelligence + enrichment. The customer brief (★) bypasses this entirely with its own 9-input dedicated pipeline. We just need to surface it.

Look at the matrix: Meeting Prep uses 10 of 11 inputs — the richest provenance story. Account Plan uses 7 inputs plus a quality scorecard and Drive upload — the hero demo. AE Voice uses only emails — the simplest. Each consumer tells a different story about what's hidden.
