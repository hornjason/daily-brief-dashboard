The Gap — What Judges Will Score

Today: User presses a button → output appears. Zero visibility into what went in, which sources loaded, what's missing, or how to improve it.
The data exists. The ProvenanceEntry[] array already tracks { source, loaded, tokenEstimate } for every input. We just need to surface it.

HIDDEN Provenance Panel

Every consumer assembles inputs behind the scenes. The user never sees which sources loaded, how many tokens each contributed, or what's missing. Exposing this is the #1 innovation opportunity.

Innovation Technical Excellence User Experience

HIDDEN Quality Scorecard

17 validators run on every account plan — section count, whitespace map, initiative depth, all deterministic checks. The pass/fail results never appear in the UI. Showing them proves AI accountability.

Innovation Technical Excellence

HIDDEN Data Maturity

The system knows exactly how complete each customer's data is — Day 0 (67%), Day 7 (89%), Day 30 (100%). This maturity score is calculated but never displayed. Surfacing it explains why outputs improve over time.

Innovation User Experience

HIDDEN Consumer Routing

Look at the matrix above — each consumer gets a different slice of signals. The user has no idea which inputs fed their output or why Meeting Prep is richer than Customer Brief. Making this visible is a UX breakthrough.

User Experience Feasibility

HIDDEN Signal Budgets

Per-source token caps prevent any single source from dominating the prompt. Tech-stack: 50, pipeline: 10, cases: 8, value-maps: 3. The user can't see or tune these — exposing them enables informed optimization.

Technical Excellence Innovation

EXISTS Template Viewer

Config templates drive output structure — scoring rubrics, planning playbooks, strategic decks fed as PDF images to Gemini. These exist but are opaque. A viewer lets users understand how the AI was instructed.
